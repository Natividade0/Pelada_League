# Origem dos recursos

`stadium_night.webp`: composição original gerada para este projeto em 13/11/2026; otimizada em WebP para uso no APK. Sem marcas, textos, jogadores identificáveis ou fotografias de terceiros.

Direção usada: estádio noturno visto do campo, arquibancadas curvas, refletores brancos e dourados, céu preto com espaço para o escudo, gramado e círculo central; estética fotográfica, sem interfaces, textos ou logotipos.

`SportArt`: escudo, coroa, bola e camisas desenhados em Canvas/Picture no código do projeto. `Ui.Icon`: ícones vetoriais originais. O avatar é uma camisa com inicial/número configurado pelo jogador, não uma fotografia fictícia de usuário.

A referência visual fornecida pelo proprietário orienta a composição; screenshots de QA são capturas reais do Android. Os valores nos testes visuais vêm de eventos de demonstração gravados no SQLite, não de números decorativos na interface.
