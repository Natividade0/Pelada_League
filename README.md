# Pelada League ⚽

Aplicativo Android nativo (Java + Gradle) para organizar peladas: sorteio de times, registro de gols, classificação e artilharia. Visual preto e dourado, inspirado na referência visual aprovada pelo criador.

**Status:** primeira alfa local; sem autenticação de usuários nem aprovação oficial de súmulas no servidor. Códigos de quatro dígitos são apenas demonstração nesta versão.

> O projeto completo será incorporado por uma etapa automatizada de inicialização. Aguarde os arquivos `app/`, `core/` e `settings.gradle` aparecerem na branch `main` antes de clonar pelo Code on the Go.
